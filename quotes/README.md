
# 🏠 装修报价管理系统

## 功能说明

这是一个完整的装修报价管理系统，支持：
- 项目管理（每个报价单独文件夹）
- 房间信息管理
- 主材选择
- 施工项目选择
- 自动报价计算

## 📁 文件夹结构

```
Quote/
├── 项目/                    # 所有项目文件夹
│   ├── 张三别墅_20260425/
│   │   ├── 图纸/           # 存放CAD图纸、图片等
│   │   ├── 报价/           # 存放报价单
│   │   └── 数据/           # 存放材料库、施工库、房间信息
│   └── 李四公寓_20260425/
│       ├── 图纸/
│       ├── 报价/
│       └── 数据/
├── 模板/                   # 报价库模板
│   ├── 材料库.json
│   ├── 施工库.json
│   ├── 房间信息.json
│   └── 报价模板.json
├── 装修报价系统.py        # 主程序 ⭐
├── 房间信息收集器.py     # 房间信息收集工具
└── 报价生成器.py         # 旧版报价生成器
```

## 🚀 快速开始

### 1. 运行主系统
```bash
python 装修报价系统.py
```

### 2. 主菜单选项

**选项 1: 创建新项目**
- 输入项目名称（如：张三别墅）
- 自动创建文件夹：张三别墅_20260425
- 自动复制模板文件
- 可选择立即开始报价

**选项 2: 查看项目列表**
- 显示所有历史项目

**选项 3: 打开现有项目**
- 选择项目继续工作
- 更新报价或查看历史数据

**选项 4: 快速报价**
- 使用当前目录文件报价
- 适合临时快速报价

### 3. 房间信息收集

如果需要先收集房间信息：
```bash
python 房间信息收集器.py
```

## 💡 使用流程

### 完整流程
1. 运行 `python 装修报价系统.py`
2. 选择"创建新项目"
3. 输入项目名称
4. 系统会自动复制当前的房间信息（如果有）
5. 选择是否立即开始报价
6. 选择材料和施工项目
7. 生成报价并自动保存到项目文件夹

### 更新已有项目
1. 运行 `python 装修报价系统.py`
2. 选择"查看项目列表"
3. 选择"打开现有项目"
4. 选择要更新的项目
5. 重新选择材料或修改项目
6. 生成新的报价（会保存新版本）

## 📊 报价计算

- **主材**: 根据选择的材料和面积计算
- **施工费**: 根据选择的项目和面积计算
- **墙面面积**: 按地面面积的3倍估算（可在房间信息中修改）
- **顶面面积**: 等于地面面积

## ⚙️ 自定义配置

### 更新报价库
1. 修改"模板/"文件夹中的 `材料库.json` 或 `施工库.json`
2. 新项目会自动使用更新后的模板

### 修改房间信息
1. 可以直接编辑 `房间信息.json`
2. 或使用 `房间信息收集器.py` 重新收集
