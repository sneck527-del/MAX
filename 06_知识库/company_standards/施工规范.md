# 斑马精装 - 公司标准化施工规范

## 水电施工标准

1. 水管走顶，电管走地，冷热水管间距≥15cm
2. 强弱电间距≥30cm，交叉处用锡纸屏蔽
3. 插座离地30cm，开关离地130cm
4. 卫生间等电位端子箱必须安装
5. 水管打压测试：0.8MPa 保压30分钟，压降≤0.05MPa

## 防水施工标准

1. 卫生间墙面防水高度≥180cm，地面满做
2. 厨房墙面防水高度≥60cm
3. 闭水试验≥48小时
4. 门槛石先铺贴再做防水

## 泥工标准

1. 瓷砖留缝≥2mm（地暖区≥3mm）
2. 墙面垂直度≤2mm（2m靠尺）
3. 地漏周边做回字形切割
4. 过门石湿铺，不可干铺
