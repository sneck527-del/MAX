# 项目全流程文件模板体系

按13个阶段组织，每份模板标注归属类别（知识库/项目文件/飞书）。

## 分类图例

| 标记 | 归属 | 说明 |
|------|------|------|
| `📖 知识库` | `06_知识库/` | 公司级可复用模板/标准，供LLM读取参考 |
| `📁 项目文件` | `项目文件夹/` | 每个项目独立生成的签字文件/过程文件 |
| `📊 飞书` | 飞书Bitable | 结构化数据，跨项目查询追踪 |
| `📁+📊` | 双存 | 签字扫描件存项目文件夹，结构化信息同步飞书 |

## 阶段与项目文件夹8大模块对照

| 阶段 | 对应项目文件夹模块 |
|------|------------------|
| 01 前期对接 | `01-前期客户对接与需求档案` |
| 02 设计方案 | `02-设计方案全文件` |
| 03 预算签约 | `03-预算报价` + `04-合同签约` |
| 04-10 施工各阶段 | `05-施工全流程管控` |
| 11 主材采购 | `06-主材定制采购` |
| 12 竣工验收 | `07-竣工交付与验收` |
| 13 售后复盘 | `08-售后维保与复盘` |

## 文件精简说明

合并/精简的文件：
1. 各施工阶段的"专项技术交底单" → 合并为通用 `分项工程技术交底单.md` (04阶段)，加阶段勾选框
2. 各施工阶段巡检记录 → 合并为通用 `施工现场巡检记录单.md` (04阶段)
3. 二次闭水试验 → 归入 `防水工程验收单` 检查项，不单独成文
4. 乳胶漆色号确认单 → 归入 `主材进场验收单` 材料信息字段
5. 质保期满确认单 → 使用率极低，不纳入标准模板
6. 瓷砖排版确认单 → 归入 `瓦工工程验收单` 前置确认项
